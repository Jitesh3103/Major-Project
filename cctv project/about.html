About CCTV-Xtract

CCTV-XTract, is an AI-powered system that analyzes CCTV video to detect people and extract key visual attributes in real time. It combines a high-performance person detector and tracker with deep learning classifiers to estimate age, gender, ethnicity, clothing style, dominant colors, and approximate height for each person. The application streams annotated frames back to the browser as the video is processed and produces a structured JSON summary and an optional PDF report at the end. It is designed for security monitoring, incident review, and rapid triage in surveillance workflows
